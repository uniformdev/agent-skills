Add breadcrumbs to this site.

- Show the trail of pages above the current one, ending with the page the visitor is on.
- Editors organise the site's pages in Uniform and move them around; the trail has to follow
  whatever structure they have set up, and stay right after they change it.
- Not every level of the site is a page you can visit.
- Some pages are product and category pages whose URLs vary.
- The markup should be accessible, and search engines should be able to read the trail.

Follow the conventions already used in this project and keep the existing components working.
