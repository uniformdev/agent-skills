Build a navigation with a mega menu.

- Hovering a flyout trigger opens a panel underneath the header.
- On the `megaMenu` variant, when the flyout contains categories, the panel shows a
  **vertical list of the category names on the left**; hovering or focusing one shows that
  category's content on the right. The first category is shown by default.
- If there is promo content, it sits beside the category content.
- A flyout with no categories just shows its contents in one panel.
- On mobile there is no hover, so show each category as its own labelled section instead.

Editors must be able to edit the link and group text inline in Uniform's visual editor, and
the menu needs to be usable with a keyboard.

Follow the conventions already used in this project and keep the existing components working.
